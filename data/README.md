# Data Directory

데이터는 크롤링/정제/테스트 목적별로 분리합니다.

## Folders

| Folder | Purpose | Commit |
| --- | --- | --- |
| `raw/` | 원본 크롤링 데이터 | 기본적으로 커밋하지 않음 |
| `processed/` | 정제/청킹/임베딩 준비 데이터 | 기본적으로 커밋하지 않음 |
| `samples/` | 테스트와 문서용 작은 샘플 | 커밋 가능 |
| `schemas/` | 데이터 스키마 초안 | 커밋 가능 |

## Principles

- 개인정보와 민감정보가 포함된 데이터는 커밋하지 않습니다.
- 원본 대용량 CSV, 임베딩 파일, 벡터 인덱스는 커밋하지 않습니다.
- 공유가 필요한 데이터는 `samples/`에 최소 크기로 가공해 둡니다.
- 데이터 처리 과정은 가능하면 `ingestion/jobs` 또는 `scripts`에 재현 가능하게 남깁니다.

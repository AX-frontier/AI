# Document Review Agent

전자결재 본문을 검토하고 형식 오류, 누락 항목, 표현 문제를 찾아 수정 방향을 제안하는 에이전트입니다.

## Scope

- 문서 유형별 규칙 관리
- 두문/본문/결문 검토
- 필수 항목 누락 확인
- 날짜, 시간, 글머리, 금액, 붙임, 끝 표기 점검
- 수정 제안 생성

## Folders

- `api/`: 문서 검토 API 계약 초안
- `rules/`: 문서 규칙, 문서 유형, 검토 기준
- `prompts/`: 검토/수정 제안 프롬프트
- `reviewer/`: 실제 검토 로직
- `tests/`: 규칙 검토 테스트
